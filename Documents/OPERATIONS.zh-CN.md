# 人工维护与发布

本文只提供可复用流程。所有域名、账号、端口和目录均应由部署者自行配置；真实运行清单、密码、备份位置、镜像 ID、访问记录和回滚证据保存在仓库外的私有运维目录。不要把填写后的实例手册提交到公开仓库。

## 仓库与构建

维护源是 `ARCJ137442/nclip`，原作者仓库是 `johnwmail/nclip`。先检查 `git remote -v` 的 URL，再选择推送目标；远端名本身不能证明目标。修改走功能分支、PR、测试和人工验收。上游官方镜像不包含本 fork 的改动。

运行 [测试指南](INTEGRATION-TESTS.md) 中的检查。需要镜像时，在 fork 的 Actions 中选择 **Share preview**，选定已验证分支并记录完整 commit SHA。下载 `nclip-preview-<SHA>` 中的镜像包与 SHA-256 文件，逐项校验后导入：

```bash
sha256sum -c nclip-image.sha256
docker load -i nclip-image.tar.gz
docker image inspect nclip:arc-<短SHA>
```

`<短SHA>` 必须人工替换。工作流仅检查并导出产物，不自动部署或推送镜像仓库。产物保留七天；采用的版本应另行归档镜像包、校验文件、源提交和构建 run ID。不要为了预演创建 `v*` 标签，已有发布工作流会响应这些标签。

## 初始化与账号

本地或容器都必须使用持久数据目录。账号模式设置 `NCLIP_ACCOUNTS=true`、初始 `NCLIP_ADMIN_USERNAME` 和 `NCLIP_ADMIN_PASSWORD_FILE`，密码通过私有文件只读挂载。容器用户 UID/GID 为 1001，数据目录需可写，秘密文件需可读。

初始化文件只在账号库不存在时使用，修改文件不会重置已有账号。通过管理页维护用户；上传、下载和管理分别授权。最后一个可用管理者受到保护。没有在线找回管理员密码的入口，恢复或离线修复之前必须停服并保存当前数据。

真实配置另建私有清单，至少记录：源提交与镜像 ID、启动参数、所有挂载、环境变量、反向代理、端口、TLS、资源限制、健康检查、日志策略以及恢复联系人。不要把完整 `docker inspect` 输出发布到 issue、PR 或 Actions。

## 升级与回滚

1. 在独立目录和回环端口预演，使用测试账号和测试密码，不挂生产数据。按目标内存上限验证文本、富文本、多文件、超限拒绝、一次性并发接收及旧接口。
2. 记录旧容器、镜像、配置和健康状态。短暂停止唯一写进程，备份整个数据目录，再校验归档与逐文件内容。包括隐藏的 `.accounts/accounts.json`，不能只备份 `data/*`。保存一份加密的异地副本。
3. 保留停止的旧容器，使用固定镜像重建应用。复用经过核对的参数、账号数据、挂载、代理与限制；一次只能有一个进程写数据。仓库的 Compose 是独立示例，不能直接覆盖已有实例。
4. 检查本机及外部健康、普通旧链接、登录/退出、权限、新私有分享和显式公网分享。只用自己创建的一次性内容做测试。失败时恢复兼容的旧容器，默认保留当前数据。
5. 若旧镜像没有应用账号保护，必须先恢复代理认证，语法检查并 reload，等待旧的无认证 worker 全部退出，再启动旧应用。reload 返回不等于 worker 已排空。

只换镜像不会撤销已发生的内容删除和账号修改。恢复旧账号库也可能恢复旧会话及权限；将恢复包解到独立目录核对后再切换，不能直接覆盖运行中的数据。

## 人工验收与日常检查

- 新隐私窗口应呈现原生登录表单；用密码管理器实际填充、提交、退出。
- 分别验证仅上传、仅下载、仅管理账号的首页和真实操作。私有链接要求登录及下载权限；显式公网分享允许匿名接收。
- 验证文本、图片、富文本和多文件的复制/下载；浏览器打开一次性页面不消耗，确认接收后才销毁。完整收到的内容可留在当前页重试。
- 真实手机 Safari 和真实扩展应单独验收，不能以移动视口模拟代替。
- 定期查看健康、日志、重启/OOM、磁盘、备份恢复和依赖更新。401 查登录，403 查权限，429 查登录限流，413 查整个请求大小。

保留正在使用和至少一个可恢复版本的镜像、准确旧容器配置及经过验证的备份。清理时先检查引用与挂载，只操作明确的旧容器、镜像和测试目录；不要使用广域 prune、带卷删除或数据清空命令。GitHub Actions 产物、GHCR 包、服务器镜像、停止容器和数据备份是不同资源，需要分别管理。

协议与存储见 [ARC-SHARING.md](ARC-SHARING.md)，认证与账号 API 见 [ACCOUNTS.md](ACCOUNTS.md)。
